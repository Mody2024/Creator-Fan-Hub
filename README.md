# Creator Fan Hub

A bespoke creator-community website and future Creator Panel.

## Current status
- Foundation branch: `development`
- Current implementation is an early visual prototype, not a production-ready platform.
- Real voting, submissions, authentication, persistence, and publishing require a trusted server/database integration before launch.

## Development principles
- Keep work on `development` until reviewed.
- Never commit credentials, API keys, or production secrets.
- Prefer accessible motion, reduced-motion support, responsive layouts, and progressive enhancement.
- The permanent “Made by Almuddaththir” signature belongs in the shared public layout.
